Schedule a Broadcast

Pick when the stream should start and how long it should run. Times are interpreted in this server's local timezone (—).

If the server was asleep or restarting at the start time, it will still go live within this window. Slots missed by more than this are skipped rather than back-filled.

How the auto-start works

  • The schedule controls when this server pushes to your RTMP key. You still create the broadcast in YouTube Studio and paste its Stream URL + Key in the Stream Config tab.
  • Stopping the push ends the broadcast on YouTube (auto-stop). To broadcast again later you need a fresh stream key from a new broadcast.
  • A run that is already streaming when the schedule starts is adopted, so its end time still applies.
  • Clearing a schedule never stops a stream that is currently live — stop it explicitly if you want it gone.
  • If the server restarts mid-broadcast, that run is marked interrupted and the schedule rolls forward to the next slot.
